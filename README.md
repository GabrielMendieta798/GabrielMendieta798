## Proyecto actual

### :robot: [AYED Autograder](https://github.com/GabrielMendieta798/ayed-autograder)

Actualmente estoy trabajando en un sistema orientado a **automatizar parte de la corrección de trabajos prácticos de Algoritmos y Estructuras de Datos**.

La plataforma procesa las entregas de los estudiantes, prepara entornos reproducibles y ejecuta validaciones automáticas sobre los proyectos.

**Tecnologías principales:**

`Python` · `FastAPI` · `Docker` · `Pytest`

El objetivo es reducir tareas manuales de corrección y lograr un proceso más rápido, consistente y reproducible.
